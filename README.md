# SI Organisasi Mahasiswa UKIP Makassar
1. Salin folder `ukip_org` ke `C:\xampp\htdocs\`. Start Apache + MySQL.
2. phpMyAdmin → Import `database/database.sql`.
3. Buka `http://localhost/ukip_org/setup.php` (sekali), lalu HAPUS file itu.
4. Login `http://localhost/ukip_org/` — admin/admin123, ketua/ketua123, 2023001/2023001.
